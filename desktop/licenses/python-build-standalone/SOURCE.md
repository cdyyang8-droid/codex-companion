# Python runtime license provenance

The Apple Silicon macOS 1.3.0 distribution was built with CPython 3.12.13
from Astral's python-build-standalone release 20260414.

These notices were retrieved from the release's source commit:
https://github.com/astral-sh/python-build-standalone/tree/7af98d60e411de479ab16f5537efc7184dffc25a

All LICENSE and LICENSE.*.txt files from that source root are included to
preserve the upstream runtime and dependency notices. This is an inclusive
collection; the presence of a notice does not mean every component is present
in the reduced application bundle. The standalone runtime's own Python
license is also copied separately by the desktop build script.
