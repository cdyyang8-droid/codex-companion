# 架构与兼容性

手机通过局域网 HTTP 与电脑 Python 服务连接，服务只读本机 Codex SQLite 数据库，并通过桌面 follower IPC 订阅活动会话。手机手动动作经配对认证、同源校验、请求指纹/轮次检查和持久化去重后，定向发送到持有会话的桌面 owner。

| 模块 | 作用 |
| --- | --- |
| `monitor.py` | 只读状态、脱敏、HTTP/SSE、桌面协议适配 |
| `pairing.py` | 六位码、持久设备凭证摘要、限流与撤销 |
| `control.py` | 审批、问题回答、文字消息的动作白名单和去重 |
| `approval_test.py` | 不执行实际命令的审批按钮测试 |
| `public/` | 任务卡片、详情、输入区与本地 Markdown 渲染 |
| `android/` | WebView、局域网发现、常亮、键盘覆盖和本机设置 |
| `desktop/` | macOS 菜单栏启动器 |

## 账号与模型

副屏不登录账号、不代管 Token，也不单独调用模型接口。是否使用 Codex 账号、直接 API Key 或兼容中转 Token，由电脑 Codex 的既有配置决定。前提是电脑上已有可工作的桌面会话和兼容的本地状态/IPC。查看进度不新增模型调用，发送文字会继续原会话并产生其正常用量。

这不是中转服务客户端或官方 App Server 替代品。Windows 和 Linux 的桌面连接未验证，不能承诺相同兼容性。浏览器展示与 Python 单元测试可在其他系统开发运行。

## 功能限制

- 仅可信局域网，当前没有 HTTPS、公网中继、锁屏推送和后台手机通知。
- 手机只支持纯文字输入，不上传附件或图片；不创建新会话，不代办账号或连接器登录。
- 内部桌面 IPC 随 Codex 升级可能变化；不可用时降级历史记录并禁止远程动作。
- 实际桌面通道已做只读往返，完整真实审批仍取决于桌面版本；自动化测试使用模拟 owner 和请求，不宣称覆盖所有真实审批种类。
- 数据库不存在或读取失败时明确显示无法获取状态，不把失败当作任务完成。
- 脱敏是尽力处理。业务文本、命令和路径可能包含工作内容；请自己选择可信任的配对设备和网络。
