# 三分钟开始使用

Codex 副屏把电脑上的任务进展放到手机上，主要用于同一 Wi-Fi / 局域网。副屏无需登录 Codex 账号，也不要求填写 API Key。电脑端已配置 API / 中转 Token 并能正常使用 Codex 时，可沿用现有会话。

## Mac 电脑

1. 解压 Mac 版本下载包，将 **Codex Companion.app** 拖进「应用程序」。当前发布包面向 Apple 芯片 Mac，macOS 13 或更新。
2. 先打开电脑上的 Codex，再双击 **Codex Companion.app**。
3. 菜单栏会出现「⌁ 副屏」，浏览器自动打开连接页面，显示 6 位配对码。关闭浏览器页面不影响后台服务。
4. 从菜单栏可以重新打开面板、查看配对码、下载 Android APK。选择「退出副屏」会停止由启动器创建的服务。

本应用当前没有 Apple Developer ID 签名和公证。macOS 可能阻止首次打开；确认来源后，在「系统设置 → 隐私与安全性」中按系统提供的「仍要打开」流程操作。不要关闭系统的全局安全保护。如果组织策略禁止未公证应用，请使用源码运行方式。

## Android 手机

1. 手机和电脑接入同一个可互通局域网。
2. 安装包内含 `codex-companion-1.3.0.apk`。也可在电脑连接页面找到 APK 下载地址，在手机浏览器输入后下载，或从 GitHub Releases 下载。
3. 打开「Codex 副屏」，选择发现的电脑并输入 6 位配对码。配对页可按需授权显示 Wi-Fi 名称。
4. 配对后自动记住电脑。点击任务查看详情，手动审批或发文字；没任务时显示时钟。

首次安装按 Android 提示允许该下载来源安装即可。之后使用同一发布签名的更新包覆盖安装，无需清除数据。

## 使用浏览器

不安装手机 App 也可以：在电脑页面点击「连接手机 → 使用链接或二维码连接浏览器」，用手机打开对应链接。浏览器常亮能力受系统限制，Android App 的常亮与全屏更稳定。

## 连不上时

- 先确认电脑 Codex 和副屏服务都在运行，电脑没有休眠。
- 两台设备必须能在局域网互相访问；访客 Wi-Fi、AP 隔离、VPN 可能阻止连接。
- 自动发现失败时，在手机「手动填写地址」中填入电脑显示的局域网地址，端口默认 `18377`。
- 电脑防火墙需允许本应用的本地网络访问。不要将端口映射到公网。
- 配对码过期后，在电脑页面点击「换一个码」。已配对设备服务重启后通常无需重配。
- 只显示「本机记录同步」时，桌面实时 IPC 可能不兼容；这时不能在手机审批，请在电脑处理。

配对数据：Mac App 存在 `~/Library/Application Support/Codex Companion/`；源码运行存在项目 `.runtime/`。移动 App 不会清除配对；源码版与 App 默认使用不同数据目录，首次切换需要重新配对。

## 退出与卸载

Mac 菜单栏选择「退出副屏」后，可以将应用移到废纸篓。若也要清除已配对设备和运行记录，再删除上述应用数据目录；源码版先停止终端中的服务，再按需移除项目 `.runtime/`。手机可按 Android 的应用管理流程卸载；清除 App 数据会清除手机保存的连接信息。电脑上的 Codex 会话不受卸载影响。
